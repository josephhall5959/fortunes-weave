FIRE EMBLEM: FORTUNE'S WEAVE

A simulation engine

A computer model of Fire Emblem: Fortune's Weave, built from the game's data. It predicts each character's stats from their growth rates and class path, fights them against level-matched enemies with the game's combat rules, and adds up what each one is good for: killing bosses, clearing maps, supporting the team, and dungeon clashes.

It was built by an AI model working from guides and data sheets. It has never played the game, so every number below is a prediction. The quickest way to judge it is to compare these numbers with your own playthrough. If something looks wrong, it may be.

Currently: 494 million Claude Opus 5.5 tokens (and counting). That covers every Claude Code session on the project since November 5, 2026 (input, output and cached context), counted November 12, 2026. Earlier chat-app conversations aren't included.

What it does

  1. Stats. Each level-up, each stat rises with probability character growth + class growth. Following a character's class path level by level gives the expected stats at any level, with the spread (good and bad level-up luck).
  2. Combat. For each fight it tries every weapon, spell and combat art the character can use. It computes Atk, damage, Hit, Crit, attack speed and follow-ups, then the foe's counter.
  3. Scenarios. The fights are run in four situations: a map (8 attacks, then an enemy phase), a boss turn, support actions, and dungeon clashes. Weapon durability and spell uses are spent across a whole map.
  4. Scores. Each character × class gets a score per role. Characters are then ranked, and the eight Divine classes are filled.

Does this match your game? Key numbers

Level 60 characters on their default class path (the classes the game puts them in) with Iron +3 weapons (the free, unlimited Part II gear), against Hard-mode enemies at level 63. How each number is computed: for every character (in its best Divine class for map play) we average over the 16 enemy types (8 types, normal and undead), then take the median character of the 60.
